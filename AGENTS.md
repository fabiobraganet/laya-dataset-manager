# Instruções do projeto

Para trabalho com GitHub Projects, issues, branches, pull requests, revisões e aprovações, leia e aplique `skills/github-workflow/SKILL.md`.

As skills versionadas deste projeto ficam em `skills/<nome>/SKILL.md`. Leia apenas as pertinentes à tarefa. A referência acima permite seu uso pelos agentes do repositório sem depender de instalação global.
